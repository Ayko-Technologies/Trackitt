# Security policy

## Reporting a vulnerability

Do not open a public GitHub issue for a security vulnerability or a privacy issue involving SMS, backups, credentials, or financial data.

Email [admin@aykotechnologies.com](mailto:admin@aykotechnologies.com) with:

- a concise description of the issue;
- affected versions and devices;
- reproducible steps or a minimal proof of concept; and
- the potential impact.

We will acknowledge reports within 7 days and aim to provide a remediation plan within 30 days. Please do not access, modify, or exfiltrate data that you do not own.

## Supported versions

Security fixes are made against the latest release and the `main` branch while Trackitt is in pre-1.0 development.
